# GPUs

Concept renders of fictional "Monaco" graphics cards (AI-generated artwork).

| File | Description |
| ---- | ----------- |
| `IMG_3184.png` | "MONACO APEX-X" — black/clear concept GPU with visible die and "RISC-V / GaN-on-Diamond" branding (1408×768) |
| `IMG_3185.png` | "MONACO TITAN-M" — red concept GPU render (1408×768) |

No build step — static image assets only.

## Viewing

`index.html` is a small static gallery page for the two renders (full-size
lightbox, download buttons, and an honest license note: both images are
fictional AI-generated concept artwork, not real products).

```bash
python -m http.server 8000
# → http://localhost:8000
```

Upload `index.html` + both PNGs to any static host to publish.
